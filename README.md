# Код-игра

Бесплатный интерактивный курс по JavaScript: 16 коротких уровней, настоящий запуск кода
в браузере, мгновенная проверка и объяснения. Без регистрации, без сервера — весь прогресс
хранится в localStorage браузера.

## Структура

| Файл | Зачем |
|---|---|
| `index.html` | весь сайт: разметка, стили и скрипты в одном файле |
| `manifest.json` | описание PWA (имя, иконки, цвета) |
| `sw.js` | service worker: офлайн-режим, стратегия «сначала сеть» |
| `icon-192.png`, `icon-512.png` | иконки приложения |
| `apple-touch-icon.png` | иконка для iOS |
| `og.png` | превью 1200×630 для соцсетей |

## Как опубликовать (GitHub Pages)

1. Создайте публичный репозиторий, например `kod-igra`.
2. Загрузите файлы из этой папки в корень репозитория (кнопка **Add file → Upload files**).
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   ветка `main`, папка `/ (root)`, **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу
   `https://<ваш-логин>.github.io/kod-igra/`.
5. Любой коммит в `main` обновляет сайт автоматически (1–2 минуты).

## Локальная проверка

Достаточно открыть `index.html` в браузере. Если нужен «как на сервере»:

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```
