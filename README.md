# Код-игра

Бесплатный интерактивный курс по JavaScript: 16 коротких уровней, настоящий запуск кода
в браузере, мгновенная проверка и объяснения. Без регистрации, без сервера — весь прогресс
хранится в localStorage браузера.

## Структура

| Файл | Зачем |
|---|---|
| `index.html` | весь сайт: разметка, стили и скрипты в одном файле |
| `manifest.json` | описание PWA (имя, иконки, цвета) |
| `sw.js` | service worker: офлайн-режим, стратегия «сначала сеть» |
| `icon-192.png`, `icon-512.png` | иконки приложения |
| `apple-touch-icon.png` | иконка для iOS |
| `og.png` | превью 1200×630 для соцсетей |
